# Quizora - AI Quiz Taker & Generator

Quizora is an interactive AI-powered quiz creation and taking platform built with Streamlit and Google Gemini.

## ✨ Features
- **Any Topic**: Generate custom multiple-choice quizzes on any academic subject, technical topic, or general knowledge.
- **Adjustable Difficulty**: Select Easy, Medium, or Hard.
- **Custom Question Count**: Generate 3 to 10 questions per quiz.
- **Instant Scoring & Feedback**: Immediate grading, percentage score, balloon celebration for top scores, and clear explanations for every question.
- **Clean FlexiQuiz Design**: Soft surfaces, card elevations, and custom theme tokens.

## 🚀 Live Deployment
- Ready to deploy on Railway with included `Procfile`, `railway.json`, and `Dockerfile`.
- Set `GEMINI_API_KEY` in environment variables.

## 🛠 Local Setup
1. Clone repo:
   ```bash
   git clone https://github.com/firered-007-dev/Quizora_.git
   cd Quizora_
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run locally:
   ```bash
   streamlit run app.py
   ```
